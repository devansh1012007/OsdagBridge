# [Bug] Generated LaTeX design report fails to compile cleanly: 281 errors from unterminated `longtable` captions (missing `\\` before `\hline`) and missing `\endfirsthead`/`\endhead`

**Severity:** High (report quality — the PDF is produced only because the compiler runs in continue-on-errors mode; every longtable after the first misaligned caption renders with broken rules/rows and the log ends with 281 errors)

**Component:** Reports — `src/osdagbridge/core/reports/chap2.py`, `chap3.py`, `chap4.py`, `chap5.py`

## Environment

- OsdagBridge commit `d74f56d` (branch `task/software-testing`)
- Python 3.12, report compiled with `pdflatex` (also reproduced with `tectonic -Z continue-on-errors`)
- Any plate-girder design run → GUI *Generate Report* (or headless `PlateGirderBridge.generate_design_report()`)

## Steps to reproduce

1. Run a design with the default template values (30 m span, 7.5 m carriageway, 4 girders, E 350A / M40).
2. Generate the design report (Report Options → all default sections).
3. Open `Report_Before.log` / recompile the emitted `Report_Before.tex`:

```bash
pdflatex -interaction=nonstopmode Report_Before.tex
```

## Expected

A clean compile (0 errors). Every `\caption{...}` inside a `longtable` environment must terminate its table row with `\\` before a `\hline`, and multi-page longtables should define `\endfirsthead`/`\endhead` so the header repeats on page breaks.

## Root cause (file:line)

`\caption{...}` directly followed by `\hline` (no `\\` row terminator). In a `longtable`, the caption row must be closed with `\\` before `\hline` can appear, otherwise `\hline` lands outside the alignment ("misplaced `\noalign`") and the following header row gets "extra alignment tab".

## Suggested fix

Terminate every longtable caption row and add header-repetition blocks. The pattern already used by the two correct tables (`chap2.py:332-336`, `chap4.py:100-…`) is:

```latex
\begin{longtable}{|L{5.5cm}|p{10.0cm}|}
\caption{\textbf{Typical Section Details}}\\
\hline
\textbf{parameter} & \textbf{value} \\
\hline
\endfirsthead
\caption{\textbf{Typical Section Details (continued)}}\\
\hline
\textbf{parameter} & \textbf{value} \\
\hline
\endhead
\textnormal{Overall Bridge Width (m)} & ... \\
\hline
\end{longtable}
```

i.e. mechanically, in each chap\*.py template string:

1. append `\\` to the caption line: `\caption{\textbf{…}}\\` (46 sites listed above);
2. duplicate the caption + header rows between `\hline` and `\endfirsthead`, then again before `\endhead`, so page-break repeats work (currently only 2 of 49 longtables do this).

A regression guard for the test-suite:

```python
def test_longtable_captions_are_terminated(tex_lines):
    in_lt, bad = False, []
    for i, line in enumerate(tex_lines):
        if "\\begin{longtable}" in line:  in_lt = True
        if in_lt and line.strip().startswith("\\caption{"):
            nxt = tex_lines[i + 1].strip()
            if not nxt.startswith("\\\\"):
                bad.append(i + 1)
        if "\\end{longtable}" in line:    in_lt = False
    assert not bad, f"{len(bad)} unterminated caption rows: {bad[:5]}"
```

(this exact test ships as `tests/functional/test_report_generation.py::TestReportGeneration::test_longtable_captions_are_terminated`, currently `xfail` — it will XPASS once the fix lands).
